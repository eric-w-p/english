# 天气

- 有风、微风：`windy` / `breezy`
- 凉快、冷：`cool` / `chilly` / `cold`
- 闷热：`muggy`
- 毛毛雨、大雨：`drizzle` / `pour` / `downpour`
- 出太阳、变热：`the sun is out` / `get hot outside`
- 春夏秋冬：`spring` / `summer` / `autumn`（`fall`） / `winter`
- 今天天气好：`It's nice out today.` / `The weather is nice today.`
- 彩虹：`a rainbow` / `see a rainbow`
- 雨暂时没下：`the rain held off` / `just long enough for us to ...`
- 最近降温：`It's gotten colder recently.` / `It's been getting colder lately.` / `the temperature dropped by five degrees`
