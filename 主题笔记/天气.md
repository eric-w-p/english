# 天气

- 有风、微风：`windy` / `breezy`
- 凉快、冷：`cool` / `chilly` / `cold`
- 闷热：`muggy`
- 毛毛雨、大雨：`drizzle` / `pour` / `downpour`
- 出太阳、变热：`the sun is out` / `get hot outside`
- 春夏秋冬：`spring` / `summer` / `autumn`（`fall`） / `winter`
