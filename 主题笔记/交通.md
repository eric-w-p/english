# 交通

从按周记录中汇总的出行、通勤与交通场景表达。

## 通勤与乘车

- 通勤：`commute to work` / `daily commute` / `commute by subway`
- 单程、往返：`one-way commute` / `round-trip commute`
- 车票：`one-way ticket` / `round-trip ticket` / `return ticket`
- 有轨电车、轻轨：`tram` / `streetcar` / `light rail`
- 地铁闸机：`fare gate` / `ticket gate` / `turnstile`
- 门禁闸门：`access gate`（强调权限控制；不一定是旋转式）
- 停车位：`temporary parking space` / `assigned parking space` / `reserved parking space` / `permanent parking spot` / `private parking space`
- 地下停车场：`underground parking garage`（美式） / `underground car park`（英式）
- 车空调坏了、送去修理厂：`my car's AC stopped working` / `take the car to a repair shop` / `drop the car off`
- 汽车后备箱：`open the trunk`（美式） / `open the boot`（英式）；`tree trunk` 是树干
- 回家路上、去办公室路上：`on my way home` / `on the way home` / `on my way to the office`
- 接人、取件、捡起、顺便买：`pick someone up` / `pick up a package` / `pick up a pen` / `pick up some cookies`
- 轮胎瘪了：`a flat tire` / `have a flat tire` / `get a flat tire`
- 沿海开车：`drive along the coast` / `coastal road`
- 靠惯性滑行：`coast downhill`

## 路况与安全

- 高峰期、非高峰期：`rush hour` / `off-peak hours`
- 人群、拥挤：`crowd` / `crowded`
- 过马路：`cross the street` / `wait at the crosswalk`
- 闯红灯：`run a red light` / `cross against the light`
- 交通事故：`traffic accident` / `car accident` / `crash`
