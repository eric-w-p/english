# 餐饮

从按周记录中汇总的点餐、食物与餐具场景表达。

## 点餐与外带

- 点餐：`Can I get ...?` / `Can I have ...?` / `I'd like ...`
- 堂食或外带：`For here or to go?`
- 打包剩饭：`to-go box` / `box up the leftovers`
- 外卖：`takeout order` / `food delivery`
- 招待客人选择饮品：`Would you like tea or coffee?` / `Would you prefer tea or coffee?`
- 咖啡加冰、去冰：`iced coffee` / `add some ice to my coffee` / `no ice`
- 咖啡加奶油、打发奶油：`cream in my coffee` / `whipped cream`
- 喝一口、尝一口：`take a sip` / `take a big sip` / `take a gulp` / `have a taste` / `try a bite`
- 美食广场：`food court`

## 食物与餐具

- 套餐附带：`come with` / `include`
- 餐具：`spoon` / `fork` / `knife` / `chopsticks` / `cutlery` / `silverware`
- 盘子、一盘饼干：`plate` / `a plate of cookies`（见 [[weeks/第43周#plate：一盘饼干与车牌]]）
- 杯套与杯垫：`cup sleeve` / `coaster`
- 煎炸与锅具：`fry` / `fry chicken` / `fried chicken` / `frying pan` / `pan` / `pot`
- 牙签：`toothpick` / `toothpicks`
- 常见食物：`fries` / `fried chicken` / `fried rice` / `bacon`
- 美式与英式饼干：`cookie` / `biscuit`
- 甜甜圈：`donut` / `doughnut` / `a glazed donut`
- 粥：`porridge` / `congee` / `rice porridge` / `a bowl of porridge` / `scoop up some congee with a spoon`
- 谷物与早餐麦片：`grain` / `cereal` / `oats` / `oatmeal` / `wheat`
- 水煮蛋与熟度：`a boiled egg` / `a soft-boiled egg` / `a hard-boiled egg`
- 蛋黄、蛋清、蛋壳：`egg yolk` / `egg white` / `eggshell`
- 剥水煮蛋：`peel a boiled egg` / `peel the shell off the egg`
- 芝麻脆块与口感：`sesame clusters` / `crunchy` / `crispy`
- 爽脆与酥脆：`crisp` / `crispy`
- 调味品：`ketchup` / `a packet of ketchup`
- 蘸食物与蘸料：`dip the fries in ketchup` / `a dip`（常较浓稠） / `dipping sauce`（范围更宽）；火锅蘸料可说 `make me some dipping sauce` / `mix me some dipping sauce`
- 水果拼盘与火龙果：`fruit platter` / `mixed fruit` / `dragon fruit`
- 一盒枣、干枣：`a box of jujubes` / `dried jujubes`（见 [[weeks/第43周#一盒枣：a box of jujubes]]）
- 椰奶与椰子水：`coconut milk` / `coconut water`
- 融化巧克力：`melt chocolate` / `melted chocolate`
- 搅拌与拌入：`stir` / `stir in ...`
- 撒配料：`sprinkle ... on/over ...`
- 食物坏了、发霉、腐烂：`go bad` / `spoiled` / `mold` / `moldy` / `rotten`
- 食物不新鲜：`stale` / `go stale`
- 牛排熟度：`How would you like your steak cooked?` / `medium rare` / `medium` / `well-done`
- 牛排熟度补充：`blue rare` / `rare` / `medium well` / `ribeye`
- 汉堡与肉饼：`burger` / `hamburger` / `beef patty` / `pork patty` / `chicken patty` / `chicken fillet`
- 鸡块、鸡爪、鸡翅：`chicken nuggets` / `chicken feet` / `chicken wings`
- 全麦与全谷物面包：`whole wheat bread` / `whole grain bread`
- 包子与饺子：`steamed stuffed buns` / `steamed meat buns` / `steamed vegetable buns` / `an order of dumplings`
- 饭后甜点：`dessert` / `have dessert` / `for dessert` / `go straight to dessert`
- 熟食店／熟食柜台：`delicatessen` / `deli`
- 招牌菜：`signature dish`
- 禽肉：`poultry`（如 chicken、turkey）
- 野味肉类：`game`（如 venison、wild duck）
