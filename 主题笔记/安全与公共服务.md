# 安全与公共服务

从按周记录中汇总的公共服务场景表达。

## 安全与安检

- 安全的、确保：`secure`
- 安全、安保：`security`
- 安检：`security check` / `go through a security check`
- 认证、授权的简称：`auth` /ɔːθ/（`authentication` 或 `authorization` 的缩写）

## 社会保障

- 社保：中国语境通常说 `social insurance`
- 社会保障制度或福利：`social security`

## 医院就诊

- 自助机：`self-service kiosk` / `self-serve kiosk`；预约后报到：`check-in kiosk`；挂号：`registration kiosk`
- 问询处：`information desk`；接待处：`reception desk`；人工挂号处：`registration desk`
- 柜台：`counter`；医院缴费柜台：`billing counter`；缴费窗口：`cashier's window` / `billing window`
- 用法与例句：[[weeks/第43周#自助机与服务台]]
