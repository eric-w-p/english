# 工作

## 工作节奏

- 工作做不完：`The work never ends.` / `There's always more work to do.`
- 开会：`have our weekly meeting` / `attend a meeting`
- 上下班打卡：`clock in` / `clock out`
- 加班：`work overtime` / `work late`
- 补卡申请：`submit a time correction request`

## 工作日常

- 带午饭、加热午饭：`bring my own lunch` / `heat it up`
- 工位午睡：`take a nap at my desk`
- 同事：`colleague` / `coworker`
- 工作地点：`at work` / `at the office` / `in the office` / `out of the office`
- 员工：`employee` / `staff` / `worker`
