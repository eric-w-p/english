# 基础表达

## 数量

- 一些、几个：`some` / `a few`
- 几乎没有：`few`

## 常用句型

- 偏好：`prefer A to B` / `prefer doing something`
- 还想做某事：`Do you still want to ...?`
- 一点点：`a tiny bit` / `a tiny little bit`

## 性质与范围

- 私人的、私密的、非公共的：`private`
- 私下地；不公开：`in private` / `keep ... private`
