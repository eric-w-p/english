# 基础表达

## 语言单位

- 字符、字母、单词、短语与句子：`character`（代码中常缩写为 `char`） / `letter` / `word` / `phrase` / `sentence`

## 数量

- 一些、几个：`some` / `a few`
- 几乎没有：`few`
- 房号里的 0：`Unit 1203`（读作 `unit twelve oh three`）
- 温度单位：`degree` / `degrees Celsius` / `degrees Fahrenheit`

## 时间

- 10 点后的分钟：`ten ten` / `ten fifteen` / `ten thirty` / `ten forty-five` / `ten fifty`
- 半点、一刻及差几分：`half past ten` / `a quarter past ten` / `a quarter to eleven` / `ten to eleven`
- 美式日期按月—日—年：`December 24, 2024` 读作 `December twenty-fourth, twenty twenty-four`；日用序数词。例句见 [[weeks/第43周#美式日期：December 24, 2024]]

## 常用句型

- 如此……以至于……：`so + 形容词/副词 + (that) + 结果从句`
- 总是、老是：`always` / `all the time`
- 问一群人：`Do you guys ...?` / `Do you all ...?` / `Do you folks ...?`
- 过来看看、再看一次：`Come take a look.` / `take a look at ...` / `take another look at ...`
- 说得通、弄明白：`That makes sense.` / `Does that make sense?` / `make sense of ...`
- 继续、发生什么事、接着做：`go on` / `What's going on?` / `go on doing` / `go on to do`
- 解释某事、作解释：`explain something to someone` / `give someone an explanation`
- 既然现在……／既然……／因为……：`now that ...` / `since ...` / `because ...`
- 无论发生什么／无论多忙：`no matter what happens` / `no matter how busy you are`
- 偏好：`prefer A to B` / `prefer doing something`
- 比较两种做法：`prefer doing A to doing B` / `prefer to do A rather than do B`
- 一般偏好与当前选择：`Do you prefer A or B?` / `Would you prefer A or B?`
- 还想做某事：`Do you still want to ...?`
- 一点点：`a tiny bit` / `a tiny little bit`

## 性质与范围

- 安装与安装过程：`install` / `installation`
- 标志、信号、签名与招牌：`sign` / `signal` / `signature` / `signature dish` / `signature product`
- 私人的、私密的、非公共的：`private`
- 私下地；不公开：`in private` / `keep ... private`
- 正式提交或归档、与“填写”区分：`filed a complaint` / `filed the receipts` / `filled out a form`
- 格式、排版：`file format` / `format a document` / `formatting`
- 产生与复现：`produce` / `reproduce a bug`
- 有效、符合要求：`valid`；`a valid ticket/passport/contract/email address`；有效期表达 `valid through` / `valid until`（见 [[weeks/第43周#valid：有效、符合要求]]）
- 额外的、额外付费：`extra napkins` / `an extra charge` / `pay extra`（见 [[weeks/第43周#extra：额外的、多付一点]]）

## 一词多义

- `bump into someone`：偶遇某人（也可指撞到人）；`bump into something`：撞上某物
- `speed bump`：减速带；`baby bump`：孕肚。用法与例句见 [[weeks/第43周#bump：偶遇、碰撞与凸起]]
- `circle`：圆圈、圈出；`social circle`：社交圈；`circle back to`：稍后回到某个话题。例句见 [[weeks/第43周#circle：圆圈、圈出、稍后再谈]]
- `steel` /stiːl/：钢；`steal` /stiːl/ → `stole` /stoʊl/ → `stolen` /ˈstoʊ.lən/：偷的原形、过去式和过去分词。例句见 [[weeks/第43周#steel、steal、stole 与 stolen]]
- `plate`：盘子；`a plate of cookies`：一盘饼干；`license plate`：车牌。例句见 [[weeks/第43周#plate：一盘饼干与车牌]]

## 人物与奖项

- 金牌、银牌：`gold medal` / `silver medal`
- 模特：`model` / `fashion model`
