# 清洁与家务

## 家务

- 做家务：`do the housework` / `do chores`
- 扫地、拖地：`sweep the floor` / `mop the floor`
- 收拾玩具：`tidy up the toys` / `put away the toys`
- 洗碗：`do the dishes`
- 洗衣服：`do the laundry` / `wash clothes`

## 清洁与洗漱

- 洗手：`hand soap` / `rub your hands together` / `lather up`
- 水龙头：`turn on the tap` / `turn off the tap`
- 清洁用品：`dish soap` / `wet wipe` / `washcloth`
