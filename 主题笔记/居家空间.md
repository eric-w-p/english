# 居家空间

## 房间

- 公寓与房屋：`apartment` / `apartment building` / `house` / `apartment complex`
- 客厅：`living room`
- 卧室：`bedroom`
- 主卧：`primary bedroom` / `master bedroom`
- 次卧：`second bedroom`；作为客房使用时可说 `guest bedroom`

## 家具

- 书架：`bookshelf`；复数 `bookshelves`
- 组装家具：`assemble the furniture` / `put the furniture together`
- 已组装好的家具：`fully assembled`
- 组装说明：`assembly instructions`
- 看说明、按说明操作、提供说明：`read the instructions` / `follow the instructions` / `give someone instructions`
