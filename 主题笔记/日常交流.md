# 日常交流

- 让一下：`Excuse me.` / `Could you let me through?` / `Can I get past?`
- 排队、插队：`wait in line` / `cut in line` / `cut in front of us` / `Excuse me, we're in line.`
- 游乐园找队伍、问等待时间：`Where's the end of the line?` / `How long is the wait?` / `We're next.`
- 指这边或那边：`here` / `there` / `over here` / `over there`
- 偶遇熟人：`bump into` / `run into`
- 在走廊擦肩而过：`pass someone in the hallway` / `pass each other in the hallway` / `walk past someone`
- 住户、居民：`resident` / `residents`
- 给你、找到了：`Here you are.` / `There you are.` / `There you go.`
- 出去玩：`hang out` / `go out`
- 有一点总比没有好：`Better than nothing.` / `Something is better than nothing.`
- 问今天感觉如何：`How are you feeling today?` / `How are you today?`
- 听到、主动听、收到消息：`hear` / `heard` / `listen to ...` / `hear from someone`
- 聊天表情与贴图：`emoji` / `sticker`
- 概括与简化：`in short` / `in brief` / `basically` / `to put it simply` / `simply put` / `to put it concisely`
- 一点忙都不帮：`not lift a finger`
- 等一下、抓紧与暂缓：`hold on` / `hold off on ...`
- 请进、到达、款式与派上用场：`come in` / `come in different colors` / `come in handy`（见 [[weeks/第43周#come in：请进、到达、款式与派上用场]]）
