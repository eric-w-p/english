# 日常生活与状态

## 状态与习惯

- 早睡、精神焕发：`go to bed early` / `feel refreshed`
- 吃得很饱：`be full` / `be stuffed`
- 饭后散步：`go for a walk`
- 刚下班：`I just got off work.`
- 玩手机、刷短视频：`be on my phone` / `scroll through short videos`
- 熬夜、通宵、睡懒觉：`stay up late` / `stay up all night` / `pull an all-nighter` / `sleep in`
- 徒步、登山：`go hiking` / `climb a mountain`
- 锻炼（动词）、一次锻炼（名词）：`work out` / `workout`
- 帐篷里吃零食、感到放松：`lie in a tent` / `have some snacks` / `feel relaxed` / `be relaxing`
- 搭帐篷、收帐篷：`set up a tent` / `pitch a tent` / `take down a tent`
- 国庆假期避开拥挤景区：`during the National Day holiday` / `crowded tourist attractions` / `would rather do A than do B`
- 阴凉处、太阳底下与影子：`in the shade` / `in the sun` / `cast a shadow`

## 个人物品与日常动作

- 给手机充电：`charge my phone` / `be running low`
- 耳机：`wireless earbuds` / `headphones`
- 乘电梯、自动扶梯：`take the elevator` / `escalator`
- 接孩子放学、请假：`pick my daughter up from school` / `take the day off`
- 带孩子去游乐园、随身带东西：`take my daughter to an amusement park` / `bring some snacks` / `carry a backpack`
- 游乐园检票：`check tickets` / `scan tickets` / `have our tickets checked`
