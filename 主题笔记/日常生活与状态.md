# 日常生活与状态

## 状态与习惯

- 早睡、精神焕发：`go to bed early` / `feel refreshed`
- 吃得很饱：`be full` / `be stuffed`
- 饭后散步：`go for a walk`
- 刚下班：`I just got off work.`
- 玩手机、刷短视频：`be on my phone` / `scroll through short videos`
- 熬夜、通宵、睡懒觉：`stay up late` / `stay up all night` / `pull an all-nighter` / `sleep in`
- 徒步、登山：`go hiking` / `climb a mountain`
- 锻炼（动词）、一次锻炼（名词）：`work out` / `workout`

## 个人物品与日常动作

- 给手机充电：`charge my phone` / `be running low`
- 耳机：`wireless earbuds` / `headphones`
- 乘电梯、自动扶梯：`take the elevator` / `escalator`
