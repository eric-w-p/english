# 第38周英语学习记录

## 餐饮

> 关联主题：[[主题笔记/餐饮]]

### 牛排与熟度

- 中文：牛排；牛排你要几分熟？
- 表达：`steak` / `How would you like your steak cooked?` / `medium rare` / `medium` / `well-done`
- 例句：How would you like your steak cooked?（您的牛排想要几分熟？）
- 补充：`blue rare` / `extra rare`（一分熟） / `rare`（三分熟） / `medium well`（九分熟） / `ribeye`（肋眼牛排）
- 例句：I'd like the ribeye, medium rare, please.（我想要一份肋眼牛排，五分熟，谢谢。）
- 提示：`How would you like ...?` 可礼貌地询问偏好，如 How would you like your coffee?（咖啡想怎么喝？）；点餐时 `I'd like ...` 比 `I want ...` 更自然。

### 汉堡里的肉饼

- 中文：牛肉饼、鸡肉饼
- 表达：`burger` / `hamburger` / `beef patty` / `pork patty` / `chicken patty`
- 例句：This burger comes with a beef patty.（这个汉堡里面有一块牛肉饼。）
- 提示：`burger` 是汉堡的统称；严格来说 `hamburger` 指牛肉汉堡，词中的 `ham` 并不是“火腿”。炸鸡汉堡里的整块鸡肉常说 `chicken fillet`；`chicken patty` 更强调“肉饼”。

### 熟食、禽肉与野味

- 中文：熟食店／熟食柜台；禽肉；野味肉类
- **表达**：`delicatessen` /ˌdelɪkəˈtesn/（常缩写为 `deli`） / `poultry` /ˈpoʊltri/ / `game` /ɡeɪm/
- **例句**：I picked up some cold cuts from the deli.（我从熟食柜台买了一些冷切肉。）
- **例句**：Chicken and turkey are both poultry.（鸡肉和火鸡肉都属于禽肉。）
- **例句**：The restaurant serves game in the autumn.（这家餐厅在秋季供应野味。）
- **提示**：`game` 在餐厅菜单上通常不是“游戏”，而是鹿肉、野兔肉、野鸭等野生动物的肉；日常说“熟食店”时，`deli` 比完整的 `delicatessen` 更常用。

## 日常交流

> 关联主题：[[主题笔记/日常交流]]

### 在走廊擦肩而过

- 中文：在走廊里遇到／与邻居擦肩而过
- **表达**：`pass someone in the hallway` / `pass each other in the hallway` / `walk past someone`
> [!example]
> I passed my neighbor in the hallway.（我在走廊里和邻居擦肩而过。）
> My neighbor and I passed each other in the hallway.（我和邻居在走廊里相向而过。）
- **提示**：这里不用 `with`。`pass someone` 表示“从某人身边经过”；`pass each other` 强调双方彼此经过。`hallway` 是走廊，常见于美式英语；英式英语也常说 `corridor`。

## 基础表达

> 关联主题：[[主题笔记/基础表达]]

### private 的用法

- 中文：私人的；私密的；非公共的
- **表达**：`private parking` / `private property` / `a private room` / `a private conversation` / `in private` / `keep ... private`
> [!example]
> This is private property. Please keep out.（这是私人领地，请勿进入。）
> I'd like to speak to you in private.（我想私下和你谈谈。）
- **提示**：`private` 可指仅供特定人使用、非公共的，如 `private parking`（私人专用停车位）；也可指不愿公开的，如 `a private conversation`（私下谈话）。`personal` 更偏“个人的、与某人有关的”，不一定有“保密”或“非公共”的意思。

### 住户与居民

- 中文：住户；居民
- **表达**：`resident` /ˈrezɪdənt/；复数：`residents`
> [!example]
> Only residents can use this entrance.（只有住户可以使用这个入口。）
- **提示**：`resident` 指住在某个地方的人，适合小区、公寓或城市等语境；`neighbor` 则特指“邻居”。不要和表示“公民”的 `citizen` 混用。

## 购物与付款

> 关联主题：[[主题笔记/购物与付款]]

### 折扣与会员

- 中文：正在打折；减价百分之十；九折优惠；会员卡；积分会员卡
- **表达**：`on sale` / `10% off` / `a 10% discount` / `membership card` / `loyalty card`
- **例句**：Are these shoes on sale?（这双鞋打折吗？）
- **例句**：Is there a discount on these shoes?（这双鞋有优惠吗？）
- **例句**：Do you have a membership card?（您有会员卡吗？）
- **提示**：说“某商品减价 10%”用 `10% off + 商品`，不说 `10% off on + 商品`；`this shoe` 指一只鞋，`these shoes` 指一双或多双鞋。

## 工作

> 关联主题：[[主题笔记/工作]]

### 考勤、工作地点与员工

- 中文：上班打卡；下班打卡；补卡申请；在上班；不在办公室；员工；全体员工
- **表达**：`clock in` / `clock out` / `submit a time correction request` / `at work` / `out of the office` / `employee` / `staff`
- **例句**：I forgot to clock in yesterday morning.（我昨天早上忘记上班打卡了。）
- **例句**：I need to submit a time correction request today.（我今天需要提交补卡申请。）
- **例句**：She's out of the office today.（她今天不在办公室。）
- **提示**：`at work` 表示在上班或工作地点；`at the office` 强调在办公室那边，`in the office` 强调在办公室里面。`employee` 指某公司的员工，`staff` 指全体员工或工作人员；`worker` 泛指工作者，常让人联想到工厂或一线工作者。

## 停车与场所

> 关联主题：[[主题笔记/交通]]

### 停车位类型

- 中文：临时车位；固定分配车位；预留专用车位；长期车位；私人车位
- **表达**：`temporary parking space` / `assigned parking space` / `reserved parking space` / `permanent parking spot` / `private parking space`
- **例句**：This space is reserved for Unit 1203.（这个车位专门留给 1203 室住户。）
- **提示**：`space` 和 `spot` 都可指车位；`assigned` 强调由公司或物业分配，`reserved` 强调预留给特定人或用途。牌子上常见 `RESERVED PARKING` 或 `PRIVATE PARKING — OWNER ONLY`。

## 天气、健康与日常用品

> 关联主题：[[主题笔记/天气]] / [[主题笔记/日常生活与状态]] / [[主题笔记/身体与护理]] / [[主题笔记/清洁与家务]] / [[主题笔记/生活用品与包装]]

### 春夏秋冬

- 中文：春天；夏天；秋天；冬天
- **表达**：`spring` / `summer` / `autumn`（美式英语也常说 `fall`） / `winter`
> [!example]
> I love autumn because the weather is cool and crisp.（我喜欢秋天，因为天气凉爽清新。）
- **提示**：谈“在某个季节”时用 `in`，如 `in spring`；`autumn` 和 `fall` 都表示“秋天”，其中 `fall` 在美式英语中更常见。

### 手指、脚趾与剪指甲

- 中文：手指；脚趾；每只手五根手指；每只脚五个脚趾；剪指甲
- **表达**：`finger` /ˈfɪŋɡər/ / `toe` /toʊ/ / `five fingers on each hand` / `five toes on each foot` / `clip your nails` / `trim your nails`
> [!example]
> We have five fingers on each hand and five toes on each foot.（我们每只手有五根手指，每只脚有五个脚趾。）
> I need to clip my fingernails.（我需要剪手指甲。）
- **提示**：`nails` 可以统称手指甲和脚趾甲；要说得更具体，可用 `fingernails`（手指甲）或 `toenails`（脚趾甲）。`clip` 和 `trim` 都可表示“剪指甲”，其中 `clip` 更强调用指甲刀剪。

### 天气、睡眠与胃部不适

- 中文：下毛毛雨；凉爽；有点冷；熬夜；通宵；睡懒觉；胃痛；胃不舒服
- **表达**：`drizzle` / `cool` / `chilly` / `stay up late` / `stay up all night` / `pull an all-nighter` / `sleep in` / `have a stomachache` / `have an upset stomach`
- **例句**：It's drizzling outside.（外面在下小雨。）
- **例句**：I stayed up late watching videos.（我熬夜刷视频。）
- **例句**：I slept in until ten this morning.（我今天早上睡到十点。）
- **例句**：I have an upset stomach.（我胃不舒服。）
- **提示**：`cool` 通常是舒服的凉爽，`chilly` 是凉飕飕的冷；`stay up late` 是睡得晚，`stay up all night` 或 `pull an all-nighter` 是整晚没睡。`sleep in` 指早上比平时晚起、睡久一点，不表示“熬夜”。

### 日用品、泡沫与快递柜

- 中文：剪刀；指甲刀；细密泡沫；气泡；快递柜
- **表达**：`a pair of scissors` / `a pair of nail clippers` / `lather` / `bubble` / `package locker` / `parcel locker`
- **例句**：Work the shampoo into a lather.（把洗发水揉搓出泡沫。）
- **例句**：Your package has been delivered to the package locker.（你的快递已经放进快递柜了。）
- **提示**：`lather` 指洗发水或肥皂搓出的细密泡沫；`bubble` 指一个个圆形气泡。`package locker` 多见于美式英语，`parcel locker` 多见于英式英语。

## 日常生活

> 关联主题：[[主题笔记/生活用品与包装]]

### 用完与存货不足

- 中文：刚好用完；用完；缺少、不够
- **表达**：`fresh out of ...` / `run out of ...` / `be short on ...`
- **例句**：We’re fresh out of milk.（我们的牛奶刚好用完了。）
- **例句**：We’ve run out of toilet paper.（我们的卫生纸用完了。）
- **例句**：We’re short on toilet paper.（我们的卫生纸不太够了。）
- **提示**：`fresh out of` 强调“刚刚彻底没有了”，常用于商店或餐馆；`run out of` 最通用；`be short on` 表示数量不足，通常还剩一点。

## 出行与场所

> 关联主题：[[主题笔记/交通]]

### 门禁闸门与旋转闸机

- 中文：门禁闸门；旋转闸机
- **表达**：`access gate` / `turnstile`
- **例句**：Please scan your badge at the access gate.（请在门禁闸门处刷工作证。）
- **例句**：Tap your card and walk through the turnstile.（刷卡后穿过旋转闸机。）
- **提示**：`access gate` 是按权限控制通行的闸门，强调“门禁”功能，不限定结构；`turnstile` 是需要推转或旋转通过的实体闸机。地铁语境中，`fare gate` 或 `ticket gate` 往往比 `access gate` 更自然。

## 安全与公共服务

> 关联主题：[[主题笔记/安全与公共服务]]

### 安全、安检与社保

- 中文：安全的、确保；安全、安保；安检；社保
- **表达**：`secure` /sɪˈkjʊr/ / `security` /sɪˈkjʊrəti/ / `security check` / `social insurance`
- **例句**：Make sure the door is secure.（确保门锁好了／门是安全的。）
- **例句**：We need to go through a security check before boarding.（登机前我们需要通过安检。）这辆摩托车队l l l
- **例句**：The company pays social insurance for its employees.（公司为员工缴纳社保。）
- **提示**：`secure` 可作形容词，意为“安全的、稳固的”，也可作动词，意为“固定好、确保得到”；`security` 是名词。你写的 `srcurity` 拼写应改为 `security`。中国语境的“社保”通常说 `social insurance`；`social security` 更常指美国等国家的社会保障制度或福利。
