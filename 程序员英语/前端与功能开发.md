# 前端与功能开发

返回 [[程序员英语/README|程序员英语]]

### 组件与状态

- **表达**：`reuse a component`（复用组件）；`keep state local`（保持局部状态）；`pass data to a child component`（向子组件传数据）
- **例句**：We can reuse the form component on the settings page.（我们可以在设置页复用这个表单组件。）
- **例句**：Let's keep the form state local and pass the selected value to the child component.（表单状态保持局部，再把选中的值传给子组件。）

### 用户交互

- **表达**：`handle a click`（处理点击）；`submit a form`（提交表单）；`show a loading state`（显示加载状态）
- **例句**：The button handles the click and submits the form.（这个按钮处理点击并提交表单。）
- **例句**：Show a loading state while the form is being submitted.（表单提交期间显示加载状态。）

### 数据请求

- **表达**：`fetch data from the API`（从接口获取数据）；`cache the response`（缓存响应）；`handle an error response`（处理错误响应）
- **例句**：The page fetches product data from the API and caches the response.（页面从接口获取商品数据并缓存响应。）
- **例句**：We still need to handle an error response if the request fails.（请求失败时，我们仍需要处理错误响应。）
- **提示**：`request` 是请求，`response` 是响应。

### 性能

- **表达**：`reduce bundle size`（减小打包体积）；`avoid unnecessary re-renders`（避免不必要的重复渲染）；`lazy-load images`（延迟加载图片）
- **例句**：We removed an unused library to reduce bundle size.（我们移除了没用到的库，以减小打包体积。）
- **例句**：Let's avoid unnecessary re-renders in this list.（我们要避免这个列表不必要的重复渲染。）
- **例句**：We lazy-load images below the fold to improve the initial load time.（我们对首屏以下的图片做延迟加载，以改善首次加载时间。）

### 可访问性与适配

- **表达**：`support keyboard navigation`（支持键盘导航）；`add an accessible label`（添加无障碍标签）；`work across screen sizes`（适配不同屏幕尺寸）
- **例句**：The dialog should support keyboard navigation.（这个对话框应支持键盘导航。）
- **例句**：The icon button needs an accessible label, and the layout should work across screen sizes.（图标按钮需要无障碍标签，布局也应适配不同屏幕尺寸。）

### 还原设计稿

- **表达**：`match the design`（与设计稿一致）；`follow the design spec`（按设计规范实现）；`spacing looks off`（间距看着不对）
- **例句**：The mobile layout doesn't match the design yet.（移动端布局还没和设计稿对齐。）
- **例句**：I'm following the design spec, but the spacing still looks off.（我按设计规范实现了，但间距看着仍不对。）

### 响应式布局

- **表达**：`responsive layout`（响应式布局）；`breakpoint`（断点）；`overflow on small screens`（小屏幕上溢出）
- **例句**：We need a responsive layout for the filter panel.（筛选面板需要响应式布局。）
- **例句**：The table overflows on small screens, so we need a different layout at that breakpoint.（表格在小屏幕上溢出，因此那个断点需要不同的布局。）

### 表单校验

- **表达**：`validate the input`（校验输入）；`show an inline error`（就地显示错误提示）；`disable the submit button`（禁用提交按钮）
- **例句**：Validate the email address before submitting the form, and show an inline error if it's invalid.（提交表单前校验邮箱地址；若无效，就地显示错误提示。）
- **例句**：Disable the submit button while the request is in progress.（请求进行期间禁用提交按钮。）

### 加载、空白与错误状态

- **表达**：`loading state`（加载状态）；`empty state`（空状态）；`error state`（错误状态）；`retry the request`（重试请求）
- **例句**：The loading state works, but the empty state still needs a message.（加载状态正常，但空状态还需要提示文案。）
- **例句**：In the error state, let the user retry the request.（出错时，让用户能够重试请求。）

### 路由与权限

- **表达**：`navigate to a page`（跳转到页面）；`redirect the user`（重定向用户）；`protect a route`（保护需要权限的路由）
- **例句**：After saving, navigate to the profile page.（保存后跳转到个人资料页。）
- **例句**：We should protect this route and redirect users who aren't signed in to the login page.（应保护这个路由，把未登录用户重定向到登录页。）

### 浏览器兼容

- **表达**：`browser compatibility`（浏览器兼容性）；`fall back to`（退回使用）；`test in Safari`（在 Safari 中测试）
- **例句**：We need to check browser compatibility before release, especially in Safari.（发布前要检查浏览器兼容性，尤其是 Safari。）
- **例句**：If the browser doesn't support this API, we can fall back to a simpler interaction.（如果浏览器不支持这个 API，可以退回使用更简单的交互。）

### 性能问题的具体描述

- **表达**：`the initial load is slow`（首次加载慢）；`the page feels sluggish`（页面感觉卡顿）；`measure the impact`（衡量影响）
- **例句**：The initial load is slow on older phones.（旧手机上的首次加载很慢。）
- **例句**：The page feels sluggish when the list gets long. Let's measure the impact before changing the rendering strategy.（列表变长时页面感觉卡顿。调整渲染策略之前，先测量具体影响。）
