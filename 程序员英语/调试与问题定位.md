# 调试与问题定位

返回 [[程序员英语/README|程序员英语]]

### 描述与复现

- **表达**：`reproduce the bug`（复现问题）；`steps to reproduce`（复现步骤）；`intermittently`（偶发地）
- **例句**：I can reproduce the bug when I refresh the page after signing in.（登录后刷新页面时，我能复现这个问题。）
- **例句**：Can you share the steps to reproduce it? It only happens intermittently on my machine.（能提供复现步骤吗？它在我电脑上只是偶发。）
- **关联**：[[weeks/第41周#produce 与 reproduce]]

### 定位原因

- **表达**：`narrow down the cause`（缩小原因范围）；`check the logs`（查看日志）；`trace the request`（追踪请求）
- **例句**：I checked the logs and narrowed the issue down to a missing token.（我查看了日志，把问题范围缩小到缺失的令牌。）
- **例句**：Let's trace the request to see where it fails.（我们追踪一下请求，看看在哪一步失败。）

### 描述根因

- **表达**：`root cause`（根因）；`be caused by`（由某种原因引起）
- **例句**：The root cause was a race condition between two requests.（根本原因是两个请求之间的竞态条件。）
- **例句**：The issue was caused by an outdated cache entry.（这个问题是由过期的缓存记录引起的。）
- **提示**：还没确认时说 `It looks like a cache issue.`（看起来像缓存问题），不要提前断言根因。

### 修复与验证

- **表达**：`fix the issue`（修复问题）；`add a regression test`（添加回归测试）；`verify the fix`（验证修复）
- **例句**：I've fixed the issue and added a regression test.（我已修复问题并添加回归测试。）
- **例句**：Could you verify the fix in staging?（能请你在预发布环境验证修复吗？）

### 说明影响范围

- **表达**：`affect older browsers`（影响较旧的浏览器）；`existing users`（现有用户）
- **例句**：This only affects users who open the page in an older browser.（这只影响用较旧浏览器打开页面的用户。）
- **例句**：It doesn't affect existing users who have already completed checkout.（已经完成结账的现有用户不受影响。）

### 收集复现信息

- **表达**：`steps to reproduce`（复现步骤）；`share a screenshot`（提供截图）；`browser version`（浏览器版本）
- **例句**：What were you doing when it happened?（出问题时你在做什么？）
- **例句**：Can you share a screenshot and your browser version?（能提供截图和浏览器版本吗？）

### 区分预期与实际

- **表达**：`expected behavior`（预期行为）；`actual behavior`（实际行为）
- **例句**：The expected behavior is that the form saves the changes.（预期行为是表单保存改动。）
- **例句**：The actual behavior is that it clears the fields without showing an error.（实际情况是它清空了字段，也没有显示错误。）

### 观察请求与控制台

- **表达**：`inspect the network request`（检查网络请求）；`check the console`（查看控制台）；`time out`（超时）
- **例句**：I inspected the network request, and it times out after ten seconds.（我检查了网络请求，它在十秒后超时。）
- **例句**：The request succeeds, but the page still shows an error. I'll check the console next.（请求成功了，但页面仍显示错误。我接下来查控制台。）

### 缩小变更范围

- **表达**：`start after a release`（从某次发布后开始）；`compare two versions`（对比两个版本）；`isolate the change`（隔离有问题的改动）
- **例句**：This started after the last release.（这个问题从上次发布后开始出现。）
- **例句**：Let's compare the two versions and isolate the change that caused it.（我们对比两个版本，找出是哪项改动造成的。）

### 前后端排查分工

- **表达**：`expected data`（预期数据）；`client side`（客户端）；`server logs`（服务端日志）
- **例句**：The API returns the expected data, but the UI doesn't update. The issue seems to be on the client side.（接口返回了预期数据，但界面没有更新。问题似乎在客户端。）
- **例句**：If the response is wrong, let's check the server logs.（如果响应不对，我们查一下服务端日志。）

### 临时规避方案

- **表达**：`workaround`（临时规避办法）；`temporary fix`（临时修复）；`root cause`（根因）
- **例句**：Refreshing the page is a workaround, but it doesn't address the root cause.（刷新页面是个临时规避办法，但没有解决根因。）
- **例句**：We have a temporary fix while we investigate the underlying issue.（排查底层问题期间，我们有一个临时修复方案。）

### 报告修复状态

- **表达**：`fix in progress`（正在修复）；`under review`（正在评审）；`couldn't reproduce it yet`（还没能复现）
- **例句**：I have a fix in progress; it should be ready for review this afternoon.（我正在修复，预计今天下午可以提交评审。）
- **例句**：I couldn't reproduce it yet, but I've added logging to help track it down.（我还没能复现，不过已经加了日志以便定位。）
