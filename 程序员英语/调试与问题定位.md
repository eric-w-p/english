# 调试与问题定位

返回 [[程序员英语/README|程序员英语]]

### 描述与复现

- **表达**：`reproduce the bug`（复现问题）；`steps to reproduce`（复现步骤）；`It happens intermittently.`（这个问题偶发）
> [!example]
> I can reproduce the bug when I refresh the page after signing in.（登录后刷新页面时，我能复现这个问题。）
- **提示**：`reproduce` 是稳定重现问题；`intermittently` 表示时有时无。

### 定位原因

- **表达**：`narrow down the cause`（缩小原因范围）；`check the logs`（查看日志）；`trace the request`（追踪请求）
> [!example]
> I checked the logs and narrowed the issue down to a missing token.（我查看了日志，把问题范围缩小到缺失的令牌。）

### 描述根因

- **表达**：`The root cause was ...`（根本原因是……）；`The issue was caused by ...`（问题由……引起）
> [!example]
> The root cause was a race condition between two requests.（根本原因是两个请求之间的竞态条件。）
- **提示**：还没确认时说 `It looks like ...`，不要提前断言 `The root cause was ...`。

### 修复与验证

- **表达**：`fix the issue`（修复问题）；`add a regression test`（添加回归测试）；`verify the fix`（验证修复）
> [!example]
> I've fixed the issue and added a regression test. Could you verify the fix in staging?（我已修复问题并添加回归测试。能请你在预发布环境验证吗？）

### 说明影响范围

- **表达**：`This only affects ...`（这只影响……）；`It doesn't affect existing users.`（它不影响现有用户）
> [!example]
> This only affects users who open the page in an older browser.（这只影响用较旧浏览器打开页面的用户。）

### 收集复现信息

- **表达**：`What were you doing when it happened?`（出问题时你在做什么？）；`Can you share a screenshot?`（能发一张截图吗？）；`Which browser are you using?`（你用的是哪个浏览器？）
> [!example]
> Can you share the steps to reproduce it and tell me which browser you're using?（能提供复现步骤，并告诉我你用的是哪个浏览器吗？）

### 区分预期与实际

- **表达**：`expected behavior`（预期行为）；`actual behavior`（实际行为）；`Instead, ...`（但实际上……）
> [!example]
> I expected the form to save the changes. Instead, it cleared the fields without showing an error.（我原本以为表单会保存改动，结果它清空了字段，也没有显示错误。）

### 观察请求与控制台

- **表达**：`inspect the network request`（检查网络请求）；`check the console`（查看控制台）；`The request times out.`（请求超时）
> [!example]
> The request succeeds, but the page still shows an error. I'll check the console next.（请求成功了，但页面仍显示错误。我接下来查控制台。）

### 缩小变更范围

- **表达**：`This started after ...`（这从……后开始出现）；`compare the two versions`（对比两个版本）；`isolate the change`（隔离有问题的改动）
> [!example]
> This started after the last release. Let's compare the two versions and isolate the change.（这个问题从上次发布后开始出现。我们对比两个版本，定位是哪项改动造成的。）

### 前后端排查分工

- **表达**：`The API returns the expected data.`（接口返回了预期数据）；`The issue seems to be on the client side.`（问题似乎在客户端）；`Let's check the server logs.`（我们查一下服务端日志）
> [!example]
> The API returns the expected data, but the UI doesn't update. The issue seems to be on the client side.（接口返回的数据符合预期，但界面没有更新。问题似乎在客户端。）
- **提示**：尚未确认时用 `seems to be`，比直接断言归属更合适。

### 临时规避方案

- **表达**：`workaround`（临时规避办法）；`temporary fix`（临时修复）；`This doesn't address the root cause.`（这没有解决根因）
> [!example]
> Refreshing the page is a workaround, but it doesn't address the root cause.（刷新页面是个临时规避办法，但没有解决根因。）

### 报告修复状态

- **表达**：`I have a fix in progress.`（我正在修复）；`The fix is under review.`（修复正在评审）；`I couldn't reproduce it yet.`（我还没能复现）
> [!example]
> I couldn't reproduce it yet, but I've added logging to help track it down.（我还没能复现，不过已经加了日志以便定位。）
