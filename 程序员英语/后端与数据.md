# 后端与数据

返回 [[程序员英语/README|程序员英语]]

### 设计接口

- **表达**：`expose an endpoint`（提供接口端点）；`validate the input`（校验输入）；`return a response`（返回响应）
> [!example]
> The service exposes an endpoint that validates the input and returns the user's profile.（这个服务提供一个接口，用来校验输入并返回用户资料。）

### 查询与存储

- **表达**：`query the database`（查询数据库）；`add an index`（添加索引）；`store a record`（存储记录）
> [!example]
> We added an index to speed up the database query.（我们添加了索引来加快数据库查询。）
- **提示**：`index` 的复数可用 `indexes`，技术语境中也常见 `indices`。

### 数据一致性

- **表达**：`update a record`（更新记录）；`run a migration`（执行数据库迁移）；`keep the data consistent`（保持数据一致）
> [!example]
> We need to run a migration before the service starts writing to the new field.（服务开始写入新字段前，我们需要执行数据库迁移。）

### 异步处理

- **表达**：`queue a job`（将任务放入队列）；`process it in the background`（在后台处理）；`retry a failed job`（重试失败任务）
> [!example]
> We queue the report generation job and process it in the background.（我们把报告生成任务加入队列，在后台处理。）
- **提示**：这里的 `job` 指后台任务，不是工作岗位。

### 分页与筛选

- **表达**：`paginate the results`（对结果分页）；`filter by status`（按状态筛选）；`sort by creation date`（按创建时间排序）
> [!example]
> The endpoint paginates the results and lets clients filter by status.（这个接口对结果分页，并允许客户端按状态筛选。）

### 修改接口

- **表达**：`add a field to the response`（在响应里增加字段）；`make a breaking change`（做不兼容变更）；`maintain backward compatibility`（保持向后兼容）
> [!example]
> Removing this field would be a breaking change, so we need to check existing clients first.（删除这个字段会造成不兼容变更，所以得先检查现有客户端。）

### 数据库事务

- **表达**：`start a transaction`（开启事务）；`commit the transaction`（提交事务）；`roll it back`（回滚事务）
> [!example]
> If the payment update fails, roll back the transaction so the records stay consistent.（如果支付更新失败，就回滚事务，以保持记录一致。）

### 缓存与过期

- **表达**：`cache the result`（缓存结果）；`invalidate the cache`（使缓存失效）；`stale data`（过期数据）
> [!example]
> The page shows stale data because the cache isn't invalidated after the update.（页面显示旧数据，因为更新后缓存没有失效。）

### 超时与重试

- **表达**：`set a timeout`（设置超时）；`retry the request`（重试请求）；`avoid duplicate processing`（避免重复处理）
> [!example]
> If the request times out, a retry must not create a second order.（如果请求超时，重试不能创建第二笔订单。）
- **提示**：重试写操作时要考虑重复执行；只说 `retry` 还不足以说明处理方式。

### 日志与追踪

- **表达**：`log the error`（记录错误日志）；`trace a request across services`（跨服务追踪请求）；`correlation ID`（关联请求的标识符）
> [!example]
> Could you share the request ID so I can trace the request across services?（能提供请求 ID 吗？我好跨服务追踪这次请求。）

### 数据修复

- **表达**：`backfill missing data`（回填缺失数据）；`check affected records`（检查受影响的记录）；`verify the migration`（验证迁移结果）
> [!example]
> After the migration, we'll backfill missing data and verify a sample of records.（迁移之后，我们会回填缺失数据，并抽样核对记录。）
