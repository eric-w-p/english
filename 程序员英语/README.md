# 程序员英语

面向前端开发，也覆盖软件工程工作的常见环节。以下是可主动练习的场景表达素材，不代表已经学过或掌握。

## 场景目录

- [[程序员英语/面试与职业介绍|面试与职业介绍]]：介绍经历、项目、技术选择、反问
- [[程序员英语/需求与团队协作|需求与团队协作]]：澄清需求、估时、同步进度、处理阻塞
- [[程序员英语/前端与功能开发|前端与功能开发]]：组件、状态、交互、性能与可访问性
- [[程序员英语/后端与数据|后端与数据]]：接口、数据库、异步任务、性能
- [[程序员英语/系统设计与安全|系统设计与安全]]：扩展性、取舍、认证与权限
- [[程序员英语/调试与问题定位|调试与问题定位]]：复现、定位、修复、说明影响
- [[程序员英语/测试与接口联调|测试与接口联调]]：测试覆盖、接口契约、环境与验收
- [[程序员英语/代码评审与版本管理|代码评审与版本管理]]：提交、PR、评审反馈、合并
- [[程序员英语/发布与线上问题|发布与线上问题]]：部署、灰度、监控、回滚与事故沟通

## 收录方式

今后遇到程序员场景的新表达：完整学习语境记在 `weeks/第N周.md`，这里的对应场景页收录精简表达并链接回该周；周记录也链接到对应场景页。实际练习表现仍以 `复习/` 为准。
