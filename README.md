# 英语学习知识库

这是一个用 Obsidian 管理、由 Codex 协助维护的英语学习知识库。`weeks/` 保留完整的按周记录，`主题笔记/` 用于跨周浏览和复习。

## 使用方式

1. 在 Obsidian 中选择“打开文件夹作为库”，然后选择此文件夹。
2. 继续按原有方式在 `weeks/` 中记录每周学到的单词、短语和表达。
3. 需要整理或复习时，直接让 Codex 基于已有周记录更新主题页、生成复习清单或关联提示。
